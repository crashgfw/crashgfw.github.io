无 ROOT 权限运行 v2rayA

发表于2020-11-16|更新于2024-07-26
|浏览量:

以非 ROOT 权限运行 v2rayA 将无法使用部分功能，例如透明代理。

然而如果你希望以 ROOT 权限运行，且已拥有 ROOT 权限而 v2rayA 判断错误，可使用 --passcheckroot 跳过 root 权限检查。

一般地，使用环境变量 V2RAYA_LITE 或命令行参数 --lite 以使用非 ROOT 权限启动 v2rayA。
